# cloudpano-ad-creatives

Public hosting for Meta ad creative files (CloudPano, PhotoAIVideo, GSV, VTPS, AutoBackgrounding).
Files are referenced by Meta via raw.githubusercontent.com URLs. Generated by Claude for Zach Calhoon's scheduled creative refresh.

- `creatives/YYYY-MM-DD/` — finished images (.jpg) and short videos (.mp4) per run
- `templates/` — HTML templates used to render image ads (Playwright) and video overlays (ffmpeg)

Stock listing photos come from Pexels (free license).
